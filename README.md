Программа не знает компьютер сама по себе и она спрашивает у Windows, а та выдаёт реальные данные: имя ПК, сколько процессоров, сколько памяти занято и т. д.

Поэтому один и тот же код на разных машинах покажет разное, у всех разное железо и настройки. Код просто задаёт вопрос, а ответ зависит от системы вот и результаты не совпадают
